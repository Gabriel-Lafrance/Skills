# Taste Flow

Shared style contract for this pack. **Other pack skills must read this and
`/architecture` before planning or writing code** (see
[../pack-shared/standards.md](../pack-shared/standards.md)).

**Read:** [doctrine.md](doctrine.md) · [examples.md](examples.md) ·
`/architecture` doctrine

## Process

1. Load taste **and** architecture doctrine before grill close, plan contracts,
   or implement briefs.
2. Carry relevant principles into Active Rules / acceptance when they are
   behavioral (e.g. fail fast at boundary, idempotent webhook).
3. Run the **implement self-check** in doctrine before acceptance evidence and
   `/code-review`.
4. `/code-review` Standards axis treats taste **and** architecture violations as
   hard unless repo docs contradict.
