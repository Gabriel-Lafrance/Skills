# Standards

[`../rules/code-quality.md`](../rules/code-quality.md) (taste) and [`../rules/code-structure.md`](../rules/code-structure.md) (architecture) are the source of truth. This file only says who applies them and when.

- **Who:** every pack skill except `/ask-gabriel`, and every Task worker that writes, reviews, or researches product code. Parents name both files in each Worker Brief **Read first** ([subagents.md](subagents.md)).
- **When:** before non-trivial work. Read each file once per session unless it is already in context.
- **Other reads:** follow the Read when table in the pack `AGENTS.md` (for example, examples only when judging a concrete shape).
- **Missing files:** the pack is not installed. Do not substitute a private checklist or a summary.

## Conflict

A repository's own instructions may add constraints. They must not weaken these rules unless the user explicitly overrides in chat.
