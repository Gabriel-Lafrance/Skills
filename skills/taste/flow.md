# Taste Flow

Shared style contract for this pack. **Other pack skills must read this before planning or writing code.**

**Read:** [doctrine.md](doctrine.md) · [examples.md](examples.md)

## Process

1. Load doctrine (KISS, named principles, non-negotiables) before grill close,
   plan contracts, or implement briefs.
2. Carry relevant principles into Active Rules / acceptance when they are
   behavioral (e.g. fail fast at boundary, idempotent webhook).
3. Run the **implement self-check** in doctrine before `/validate`.
4. `/code-review` Standards axis treats violations as hard unless repo docs
   contradict.
