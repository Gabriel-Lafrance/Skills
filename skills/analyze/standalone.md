# Analyze (standalone)

One-off research outside a parent wave. Read [doctrine.md](doctrine.md).

## Process

1. Establish or refresh the relevant execution context and normalize the ask.
2. Investigate via Task workers per [../pack-shared/subagents.md](../pack-shared/subagents.md): non-trivial research **must** use a Task; parallelize independent surfaces, then synthesize the evidence.
3. Post the analysis memo, including an inline `/goal` seed when the work is buildable.
4. Ask one batch for real unknowns, then offer the explicit hand-off choices in doctrine (Done / Sharpen / Promote / Write ticket / Promote + start).

Do not invent a parent brief or skip the hand-off Questions unless the user already named the next step.
